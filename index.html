Обери модель за тим, що вимірюєш і як відбувається дослід.

Як читати розподіл

Випадкова величина X ставить у відповідність число кожному результату досліду. Її розподіл визначає, які значення можливі та як між ними розподілена ймовірність.

Ряд імовірностей

Для дискретної величини кожне можливе значення має свою ймовірність. Сума всіх імовірностей дорівнює 1.

Густина

Для неперервних моделей імовірність інтервалу дорівнює площі під кривою. Одна точка має нульову ймовірність, навіть коли її густина додатна.

Функція F(x)

Накопичує ймовірність від 0 до 1. У дискретному розподілі висота стрибка дорівнює ймовірності значення. За F(x) = P(X ≤ x) межа входить у суму. За F(x) = P(X < x) беремо лише менші значення.

Який розподіл обрати

Один процес, різні запитання

Незалежні спроби зі сталим шансом успіху

Результат однієї спроби описує розподіл Бернуллі, кількість успіхів за n спроб — біноміальний, а номер першої успішної спроби — геометричний.

Потік подій зі сталою інтенсивністю

Для однорідного пуассонівського потоку кількість подій за хвилину має розподіл Пуассона, а час до наступної події — експоненційний.

Що показують характеристики

Сподівання M(X)

Середнє, зважене за ймовірностями результатів. Для дискретної величини M(X) = Σ xᵢpᵢ.

Дисперсія D(X) і відхилення σ

Дисперсія усереднює квадрати відстаней від сподівання. Корінь σ = √D повертає міру розкиду в одиниці X.

Мода

Для дискретної величини це значення з найбільшою ймовірністю. Для моделі з густиною це точка її максимуму. Мод може бути кілька.
